## 🟢 SECTION 1: DevOps Fundamentals

### Q1. What is DevOps?

**Model Answer:**

> DevOps is a set of practices that combines development and operations to deliver applications faster and more reliably by using automation, collaboration, and continuous delivery.

---

### Q2. Why do companies use DevOps?

**Model Answer:**

> Companies use DevOps to reduce deployment time, minimize errors, improve collaboration between teams, and deliver features faster to customers.

---

### Q3. What are the main phases of DevOps?

**Model Answer:**

> Plan, Code, Build, Test, Release, Deploy, Operate, and Monitor.

---

## 🟢 SECTION 2: CI/CD (Very Important)

### Q4. What is CI/CD?

**Model Answer:**

> CI/CD stands for Continuous Integration and Continuous Delivery. It is an automated process where code changes are built, tested, and deployed automatically.

---

### Q5. What is Continuous Integration (CI)?

**Model Answer:**

> Continuous Integration is the practice of frequently merging code changes into a shared repository and automatically running builds and tests to detect issues early.

---

### Q6. What is Continuous Delivery / Deployment?

**Model Answer:**

> Continuous Delivery ensures code is always in a deployable state, while Continuous Deployment automatically deploys every successful change to production.

---

### Q7. Why is CI/CD important?

**Model Answer:**

> CI/CD reduces manual errors, speeds up releases, ensures consistent deployments, and improves software quality.

---

### Q8. What tools are used for CI/CD?

**Model Answer:**

> Common tools include GitHub Actions, Azure DevOps, Jenkins, GitLab CI/CD, and AWS CodePipeline.

---

### Scenario Question (Very Common)

> Your team is facing frequent deployment failures. How does CI/CD help?

**Expected Answer:**

> CI/CD automates builds and testing, catches issues early, ensures consistent deployments, and reduces human error.

---

## 🟢 SECTION 3: Docker & Containers

### Q9. What is Docker?

**Model Answer:**

> Docker is a containerization platform that packages an application and its dependencies into a container so it runs consistently across different environments.

---

### Q10. What is a container?

**Model Answer:**

> A container is a lightweight, isolated environment that runs an application along with its required libraries and dependencies.

---

### Q11. Difference between VM and Docker container?

**Model Answer:**

> Virtual Machines include a full operating system and are heavier, while containers share the host OS kernel and are lightweight, faster, and more efficient.

---

### Q12. What is a Docker image?

**Model Answer:**

> A Docker image is a read-only template used to create containers. It contains application code, dependencies, and configuration.

---

### Q13. What is a Dockerfile?

**Model Answer:**

> A Dockerfile is a text file with instructions to build a Docker image, such as base image, dependencies, and commands.

---

### Q14. What is Docker Hub?

**Model Answer:**

> Docker Hub is a public container registry used to store and share Docker images.

---

### Scenario Question

> Why is Docker useful in DevOps?

**Expected Answer:**

> Docker ensures consistency across development, testing, and production environments, reducing “it works on my machine” issues.

---

## 🟡 SECTION 4: Cloud + DevOps Basics

### Q15. How does DevOps work with cloud?

**Model Answer:**

> Cloud provides scalable infrastructure, and DevOps automates deployments on it using CI/CD pipelines, containers, and monitoring tools.

---

### Q16. What is Infrastructure as Code (IaC)?

**Model Answer:**

> Infrastructure as Code is the practice of managing infrastructure using code instead of manual configuration, making deployments consistent and repeatable.

---

### Q17. What are examples of IaC tools?

**Model Answer:**

> Terraform, AWS CloudFormation, Azure ARM templates, and AWS CDK.

---

## 🟡 SECTION 5: Monitoring & Reliability

### Q18. Why is monitoring important in DevOps?

**Model Answer:**

> Monitoring helps detect performance issues, failures, and security incidents early, ensuring system reliability.

---

### Q19. What do you monitor in production?

**Model Answer:**

> CPU, memory, disk usage, application logs, error rates, and response times.

---

### Q20. What happens after deployment in DevOps?

**Model Answer:**

> After deployment, applications are monitored, logs are analyzed, feedback is collected, and improvements are made continuously.

---

## 🔵 SECTION 6: DevOps Fresher Final Questions

### Q21. Explain a simple CI/CD pipeline you built

**Model Answer:**

> I used GitHub for code, configured a CI/CD pipeline to build the application, run tests, and deploy it automatically to a cloud environment.

---

### Q22. What DevOps skills do you have as a fresher?

**Model Answer:**

> I understand CI/CD concepts, Docker containers, basic cloud deployments, version control, and monitoring fundamentals.

---

### Q23. How do you handle deployment failures?

**Model Answer:**

> I would check pipeline logs, roll back to the previous stable version, identify the root cause, and fix the issue before redeploying.
