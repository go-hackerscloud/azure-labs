Here’s a **clickable list of FREE official Microsoft Azure hands-on labs & sandbox learning resources** for **GoHackersCloud cloud roadmap**.

Where available, these labs include **built-in Azure sandbox environments** so learners can *practice hands-on without needing their own subscription* ([Microsoft Learn][1]).

---

# ☁️ Azure Hands-On Labs (Official Microsoft Learn & More)

### 🔹 Azure Fundamentals & Beginner Labs

**Start here — built-in sandbox exercises to get real experience**

* 👉 **Microsoft Learn: Azure Training Overview & Labs** — All Azure learning paths with modules and hands-on exercises (Azure sandbox available in many modules) ([Microsoft Learn][2])
  [https://learn.microsoft.com/en-us/training/azure/](https://learn.microsoft.com/en-us/training/azure/)

* 👉 **Course: AZ-900T00-A – Introduction to Cloud Infrastructure**
  Beginner lab course covering core Azure concepts with practical exercises using the portal ([Microsoft Learn][3])
  [https://learn.microsoft.com/en-us/training/courses/az-900t00](https://learn.microsoft.com/en-us/training/courses/az-900t00)

* 👉 **Microsoft Azure Portal Quickstart & Hands-On** — learn how to create and manage resources via Azure portal (has sandbox support in Learn modules) ([Microsoft Learn][4])
  [https://learn.microsoft.com/en-us/azure/azure-portal/](https://learn.microsoft.com/en-us/azure/azure-portal/)

---

### 🧪 Azure Sandbox Practice Support

> Many Microsoft Learn modules automatically enable a **sandbox environment** without needing your own credits. You can start the sandboxes straight from the Learn page and practice core Azure services (VMs, storage, networking, identity, monitoring). ([Microsoft Learn][5])

* 👉 **How to Access the Azure Learn Sandbox** — step-by-step guidance on accessing sandbox labs directly on Learn modules ([Microsoft Learn][6])
  [https://learn.microsoft.com/en-sg/answers/questions/2281908/how-to-i-access-sandbox-%28free-learning-and-labs%29-f](https://learn.microsoft.com/en-sg/answers/questions/2281908/how-to-i-access-sandbox-%28free-learning-and-labs%29-f)

### 📘 Azure Admin Labs & GitHub Resource Guides

These are technical lab roadmaps hosted on GitHub with guided instructions — **great for Stage 3+ Azure learning & real scenarios**:

* 👉 **AZ-104 Microsoft Azure Administrator Labs (GitHub)** — includes labs such as Virtual Networking, Entra ID, Governance, Deployments, and more (self-hosted lab instructions you can follow) ([microsoftlearning.github.io][7])
  [https://microsoftlearning.github.io/AZ-104-MicrosoftAzureAdministrator/](https://microsoftlearning.github.io/AZ-104-MicrosoftAzureAdministrator/)

### 📦 Additional Free Lab Resources (Simulations & Practice)

These aren’t Microsoft sandboxes but are **free simulated labs** great for extra practice:

* 👉 **Free Azure Lab Simulations (labITPRO)** – a curated list of ~12 free Azure labs that simulate real tasks without needing an Azure subscription ([labIT PRO Suite][8])
  [https://labitpro.com/free-azure-lab-collection/](https://labitpro.com/free-azure-lab-collection/)

* 👉 **Azure DevOps Hands-On Labs** – practice Azure DevOps scenarios, CI/CD pipelines, repos, and more (great for DevOps stage) ([azuredevopslabs.com][9])
  [https://www.azuredevopslabs.com/](https://www.azuredevopslabs.com/)

---

# 📌 Tips for Using These Labs

✅ **Activate the Sandbox** in Microsoft Learn modules when prompted — it gives *temporary free resource access* for the lab. ([Microsoft Learn][1])
✅ If a sandbox isn’t available, learners can use **Azure Free Account / Azure for Students** for hands-on deployments (Azure offers credits & free tiers). ([Microsoft Azure][10])
✅ Add a **lab README and architecture diagram** to your portfolio for every major lab.

## 📍 Suggested Azure Labs by Roadmap Stage

**Stage 1 – Fundamentals**

* AZ-900 Learning Path modules (sandbox)
* Portal Quickstart exercises

**Stage 2 – Compute & Storage**

* VM creation & configuration modules
* Storage account lab exercises

**Stage 3 – Networking & Identity**

* Virtual Networking tutorials
* Azure AD user & RBAC labs

**Stage 4 – Monitoring & Ops**

* Azure Monitor / Log Analytics modules
* Cost management labs

**Stage 5 – DevOps**

* Azure DevOps Pipelines labs
* GitHub CI/CD integration exercises

**Stage 6 – Capstone**

* Combine above to deploy a secure web app + monitoring
